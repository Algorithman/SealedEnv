# SealedEnv — Build Plan

> Source-generated, AOT-friendly, strongly-typed environment variable configuration for .NET.
>
> ```csharp
> [SealedEnv(Prefix = "MYAPP_")]
> public sealed partial record AppConfig(
>     [EnvKey("PORT", Default = "8080")] int Port,
>     [EnvKey(Required = true)] string DbConnection,   // → MYAPP_DBCONNECTION
>     [EnvKey] TimeSpan ShutdownTimeout);              // → MYAPP_SHUTDOWNTIMEOUT
>
> var cfg = AppConfig.Load();        // throws SealedEnvException aggregating ALL errors
> ```
>
> Value proposition: no reflection (NativeAOT-safe), compile-time validation, structured
> errors listing every bad variable at once, and a testable provider seam.

Target: NuGet v0.1.0-alpha in roughly 8–10 focused evenings (~3–4 weekends).

---

## 1. API design decisions (make these first, they drive everything)

| Decision | Choice for v1 | Rationale |
|---|---|---|
| Carrier type | `sealed partial record` with primary constructor | Config as immutable value type; generator only adds static members, never mutates user signature |
| Type attribute | `[SealedEnv(Prefix = "...")]` on record/class | Sets key prefix + options for the whole type |
| Member attribute | `[EnvKey]` on primary-constructor parameters | Source generators cannot add ctor parameters, but can read them; keys default to `SCREAMING_SNAKE_CASE` of the parameter name |
| Lookup seam | `IEnvProvider { string? Get(string key); }` + `EnvironmentEnvProvider` default | Makes everything unit-testable; enables dotenv adapters later |
| Errors | Both APIs: `Load()` (throws aggregate `SealedEnvException`) and `TryLoad(out cfg, out IReadOnlyList<EnvError>)` | Exceptions for app startup, structured errors for tests/CLIs |
| Defaults | Stored as `string` in the attribute, parsed by the same pipeline as env values | One parsing path, zero special cases |
| Empty string | Treated as unset by default (`EmptyAsUnset = true`), opt-out flag | Matches dotenv conventions; avoids the classic `PORT=""` footgun |
| Unknown types | Must implement `IParsable<T>` (static abstract interface) or supply `[EnvKey(Parser = typeof(X))]` | Generated code calls `IParsable<T>.Parse(value, null)` directly on the concrete type — fully AOT-safe, zero boxing |
| Culture | Always `CultureInfo.InvariantCulture` | Config is not locale-dependent |
| Collections | `string[]`, `IReadOnlyList<string>`, `T[]` where `T : IParsable<T>` — split on `Separator` (default `,`), `\,` escape, trim entries | Covers 90% of real use; document loudly |

### Public surface (runtime package)

```csharp
namespace SealedEnv;

[AttributeUsage(AttributeTargets.Class | AttributeTargets.Struct, AllowMultiple = false)]
public sealed class SealedEnvAttribute : Attribute
{
    public string? Prefix { get; set; }
    public bool EmptyAsUnset { get; set; } = true;
}

[AttributeUsage(AttributeTargets.Parameter, AllowMultiple = false)]
public sealed class EnvKeyAttribute : Attribute
{
    public EnvKeyAttribute() { }
    public EnvKeyAttribute(string key) { }
    public bool Required { get; set; }
    public string? Default { get; set; }
    public bool AllowEmpty { get; set; }
    public char Separator { get; set; } = ',';
    public string? Description { get; set; }          // consumed by future doc export
    public Type? Parser { get; set; }                  // type exposing: static T Parse(string)
}

public interface IEnvProvider { string? Get(string key); }
public sealed class EnvironmentEnvProvider : IEnvProvider { /* Environment.GetEnvironmentVariable */ }
public sealed class DictionaryEnvProvider : IEnvProvider { /* for tests */ }

public enum EnvErrorCode { Missing, Empty, Invalid, Duplicate }
public sealed record EnvError(string Key, EnvErrorCode Code, string Message, string TypeName);
public sealed class SealedEnvException : Exception { public IReadOnlyList<EnvError> Errors { get; } }
```

### Expected generated output (contract to test against)

```csharp
// <auto-generated/>
#nullable enable
public sealed partial record AppConfig
{
    public static AppConfig Load(SealedEnv.IEnvProvider? provider = null)
    {
        provider ??= SealedEnv.EnvironmentEnvProvider.Instance;

        string? __dbConnection = provider.Get("MYAPP_DBCONNECTION");
        // ... read all keys first, then validate all, then construct

        var __errors = new System.Collections.Generic.List<SealedEnv.EnvError>();

        int __port = SealedEnv.SealedEnvLoader.Int(provider, "MYAPP_PORT", "8080", ref __errors, "AppConfig.Port");
        // primitives via generated helper calls; keep generated code SHORT, logic in runtime lib

        if (__errors.Count > 0) throw new SealedEnv.SealedEnvException(__errors);

        return new AppConfig(__port, __dbConnection!, __shutdownTimeout);
    }

    public static bool TryLoad(out AppConfig? config, out System.Collections.Generic.IReadOnlyList<SealedEnv.EnvError> errors, SealedEnv.IEnvProvider? provider = null) { ... }
}
```

**Key generation principle:** the generator emits *thin* code; all parsing/validation logic lives in the
runtime library as `internal static` helpers (`SealedEnvLoader.Int/Bool/TimeSpan/Uri/Enum<T>/Parsable<T>/...`).
Generator changes then require far fewer snapshot-test updates.

**Packaging model (Vogen-style, single package):** `SealedEnv.nupkg` contains the runtime lib plus the
generator assembly under `analyzers/dotnet/cs/`. Consumers do one `dotnet add package SealedEnv`.
Split into `SealedEnv` / `SealedEnv.Generators` only if the runtime ever needs to exist without generation.

**Critical csproj wiring** (the classic source-generator footgun):

```xml
<!-- in the CONSUMER project (tests, sample) -->
<ItemGroup>
  <ProjectReference Include="../../src/SealedEnv/SealedEnv.csproj"
                    OutputItemType="Analyzer" ReferenceOutputAssembly="false" />
</ItemGroup>
```

Generator csproj: `netstandard2.0`, packages `Microsoft.CodeAnalysis.CSharp` (pin a 4.x floor, e.g. 4.11.0 —
newer SDKs load older Roslyn-targeting generators fine, the reverse is not true), `PrivateAssets=all`.

Runtime lib: `net10.0` (fall back to `net8.0` if your SDK is older); C# 13+ for partial-property readiness;
`IsAotCompatible=true` on the runtime project so CI catches trim/AOT warnings early.

### Phase 3 — Validation & diagnostics (1–2 evenings)
- [x] Full semantics matrix (test each cell — this is the heart of the library):

| Configuration | Unset | Empty string | Malformed |
|---|---|---|---|
| value type, no default | `Missing` error | `Empty` error (or unset if `EmptyAsUnset`) | `Invalid` error |
| `string`, not required, not nullable | `Missing` error | `Empty` error | — |
| `string?` | `null` | `""` | — |
| `Required = true` | `Missing` error | `Empty` error unless `AllowEmpty` | `Invalid` error |
| `Default` given | default parsed & used | per `EmptyAsUnset`/`AllowEmpty` | default malformed → generator diagnostic at compile time |

  Every cell has a generated-carrier test (`SemanticsMatrixTests`); decisions pinned beyond the table:
  `EmptyAsUnset` applies before requiredness (empty + required → `Missing`, not `Empty`), a default does
  NOT rescue an explicit empty when `EmptyAsUnset=false` (the error wins), a present-but-malformed value
  beats a well-formed default, and `string?` under `EmptyAsUnset=true` maps `""` → `null` (the pipeline
  was adjusted in Phase 3: `string?` members never raise `Empty` — `""` is a real value unless
  `EmptyAsUnset` maps it to unset).
- [x] Aggregate errors: collect ALL, never fail-fast (one startup = complete report)
- [x] Runtime `SealedEnvException.Message`: multi-line, one error per line, key + type + cause
- [x] Compile-time diagnostics (prefix `SVE` — distinctive, collision-free):
  - `SVE0001` `[EnvKey]` on non-primary-constructor location — implemented via a dedicated `CreateSyntaxProvider` pass (method/ctor/lambda/delegate/local-function params); non-parameter locations are already hard compiler errors via `AttributeTargets.Parameter` (CS0592), which the generator stays out of
  - `SVE0002` unsupported parameter type (no parser route) ✅ Phase 2
  - `SVE0003` duplicate resolved key ✅ Phase 2
  - `SVE0004` `Default` value does not parse as the parameter type — mirrors the runtime rules (invariant culture, strict double, absolute Uri, the bool token set, `Enum.TryParse` member/numeric/flag-list semantics); `string`/`string[]` accept anything; `IParsable<T>`/custom `Parser` routes are runtime-only (the generator cannot execute their parsers)
  - `SVE0005` carrier type is not `sealed` (record structs implicitly pass)
  - `SVE0006` `Parser` type lacks `public static T Parse(string)` — method-group shape: public, static, non-generic, one string parameter, returns the parameter's exact type
  - Error severities; test each via a diagnostics test harness ✅ (`SVE0002`/`SVE0004`/`SVE0006`/`SVE0007` block generation; `SVE0003` still generates deterministically)
- [x] `TryLoad` never throws — covered by tests (hostile-environment test: overflow, control chars, emoji, separator-only lists)

**Exit criteria:** every table cell + every diagnostic has a passing test. ✅

### Phase 6 — Benchmarks & docs (1 evening)
- [x] BenchmarkDotNet, four scenarios on a 6-field record: raw `Environment.GetEnvironmentVariable` + manual parse (floor), SealedEnv `Load()`, `Microsoft.Extensions.Configuration` binder (reflection path), `DotNetEnv` — all scenarios read the same six `BENCH_*` vars set by a shared `[GlobalSetup]` inside BDN's isolated process (dev machine env untouched). ### Post-plan: adversarial hardening round (found by attacking the library itself)

- **Uri was platform-dependent** — on Unix, `Uri.TryCreate("/path", UriKind.Absolute)` maps POSIX paths onto `file:///path`, so the same env value was valid on Linux and `Invalid` on Windows (first caught by ubuntu CI). Fixed on both sides (runtime loader + SVE0004 mirror) with an explicit-RFC-3986-scheme check before consulting the BCL.
- **A throwing provider broke the TryLoad-never-throws contract** — `provider.Get` is now guarded; the failure records an ordinary `Invalid` error naming the provider type and key.
- **Whitespace-padded `[SealedEnv]` prefixes silently produced unmatchable keys** (" myprefix" → " MYPREFIXPORT") — new blocking diagnostic **SVE0009** covers leading/trailing whitespace; internal whitespace and the empty string stay legal (visible and plausibly deliberate / documented global-key syntax).
- **Pinned edge semantics:** derived keys uppercase char-wise (`Größe` → `GRÖßE`, no full case folding); `1e999` overflows to ±Infinity like the BCL (NaN/±Infinity acceptance was already pinned in Phase 1); `AllowEmpty` on a parsed member yields `Invalid`, not a crash; newline/NUL/100k-char payloads pass through string members.
- **Second round — parser and carrier-shape attacks:** parsers are user code, so the loader now survives ANY parser exception (the old catch list was FormatException/OverflowException/ArgumentException only) and rejects parser-null results (which used to smuggle a null member into a successful load); carriers without a primary constructor are blocked with **SVE0010** instead of generating a useless zero-member Load — `[SealedEnv]` now finds the primary constructor through the type symbol, so it may sit on any partial declaration (implicit ctors excluded — the record copy constructor has one parameter of the carrier's own type and must not be mistaken for the primary); case-variant duplicate keys (`port` vs `PORT`) are flagged SVE0003 with a modulo-case note because they read the SAME variable on Windows; exotic enum underlying types (byte/long/ulong flags) pinned — `Enum.TryParse` never throws and byte-range overflow is `Invalid`.
- **Attack fixtures added:** hostile-key E2E carrier (`@class`/`@event` keyword params, keys with quotes/backslashes/newlines), plain-struct carrier E2E, same-type-name-in-two-namespaces (hint-name collision probe — namespace is part of the hint name, so no collision), 100-parameter scale carrier, whitespace-prefix theories. Generator meta-lesson: an unregistered diagnostic crashes the whole generator (CS8785) — the per-diagnostic tests are the net that catches wiring mistakes.
